# 하루핏

고등학생을 위한 간단한 수면·운동 습관 웹 앱입니다. HTML, CSS, JavaScript만 사용하며 설치, 회원가입, 서버 없이 작동합니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 기록은 해당 브라우저의 `localStorage`에 저장되며 외부로 전송하지 않습니다. 브라우저 데이터 삭제 시 기록도 지워집니다. 파일 주소에서 저장을 제한하는 브라우저는 아래 로컬 서버를 사용하세요.

Node.js가 있다면 프로젝트 폴더에서 `node server.js`를 실행하고 <http://localhost:3000>에 접속하세요. 종료는 `Ctrl+C`입니다. 브라우저 알림은 localhost 또는 HTTPS와 사용자 권한이 필요하며, 지원하지 않는 환경에서는 화면 안 알림을 사용합니다.

## 사용

1. 기상 날짜와 취침·기상 시간을 입력하고 저장합니다. 자정을 넘긴 수면은 자동 계산하며, 동일 날짜의 재저장은 수정으로 처리합니다.
2. 오늘의 운동 제안을 확인하고 실제 실천한 뒤 완료 버튼을 누릅니다. 다시 누르면 취소됩니다.
3. 최근 7일 그래프에서 수면 시간과 완료 여부를 확인합니다. 막대를 누르면 그날의 수면을 수정할 수 있습니다.
4. 시험 기간·방학 모드를 선택하거나 취침·운동 알림 시간을 설정합니다.

## 간단한 추천 규칙

| 조건 | 기본 목표 |
| --- | --- |
| 수면 6시간 미만 또는 점수 60점 미만 | 가벼운 스트레칭 5분 |
| 수면 8시간 미만 또는 점수 80점 미만 | 편안하게 걷기 10분 |
| 나머지 | 가벼운 맨몸운동 15분 |

- 시험 기간은 최대 10분, 방학은 수면 8시간 이상·점수 80점 이상일 때 5분 추가합니다.
- 점수는 8시간을 기준으로 계산합니다. 직전 6일 중 기록이 2개 이상이면 수면 시간 80점 + 규칙성 20점입니다. 규칙성은 현재 취침·기상 시각과 이전 기록들의 평균 시각 차이를 반영하고, 자정 전후의 차이는 짧은 방향으로 계산합니다. 이전 기록이 부족하면 수면 시간만으로 100점 척도를 계산합니다.
- 평균 수면은 최근 7일 중 기록이 있는 날만 계산합니다. 운동 달성률은 오늘 포함 최근 7일을 분모로 하며 미기록일도 포함합니다. 연속 달성일은 오늘 미완료인 경우 어제부터 계산합니다.
- 수면별 달성률 비교는 최근 7일에 8시간 이상·미만 수면 기록이 각각 2일 이상일 때만 표시합니다. 상관계수나 인과관계를 주장하지 않습니다.
- 완료 당시의 운동명과 시간을 별도로 보관하므로 나중에 모드나 수면을 바꿔도 완료 기록의 내용은 유지됩니다.

## 범위와 제한

- 알림은 **페이지가 열린 동안** 설정 시각 직후 2분 안에 확인될 때 표시됩니다. 운동 알림을 보냈고 미완료라면 30분 뒤 한 번 더 표시합니다. 자정을 넘기는 재알림은 생략합니다. 브라우저 절전·백그라운드 제한에 따라 지연되거나 놓칠 수 있습니다.
- 앱 종료 후 푸시 알림, 홈 화면 위젯·잠금화면 연동은 이 간단한 웹 버전에 포함하지 않습니다.
- 수면 시간은 입력 시각의 차이로 계산한 24시간 미만 기록입니다. 실제 잠든 시간, 중간 각성, 수면의 질은 자동 측정하지 않습니다.
- 점수와 운동 시간은 **시연용 습관 형성 규칙**이며 의학적으로 검증한 운동 처방이 아닙니다. 수면만으로 안전한 운동 강도를 판단할 수 없습니다.
- 청소년의 일반적인 권장 수면은 [8~10시간(CDC)](https://www.cdc.gov/sleep/about/), 신체활동은 [하루 60분 이상(CDC)](https://www.cdc.gov/physical-activity-basics/guidelines/children.html)입니다. 앱의 짧은 목표가 하루 전체 권장량을 대체하지 않습니다.

## 파일

- `index.html`: 화면
- `style.css`: 모바일 대응 스타일
- `logic.js`: 수면·점수·추천·주간 집계 계산
- `app.js`: 입력, 저장, 화면 갱신, 알림
- `server.js`: 선택 사항인 외부 의존성 없는 로컬 서버
- `logic.test.js`: 계산 로직 테스트 (`node --test logic.test.js`)
